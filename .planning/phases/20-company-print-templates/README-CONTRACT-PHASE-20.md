## Найдено и исправлено в этой фазе

   AttributeError на старте) — импорт алиасирован `settings_routes`.
2. **Двойное экранирование** текстов шаблона: render_text экранировал + Jinja
   autoescape поверх → «&amp;amp;» на печати. Экранирование отдано Jinja.
3. **MissingGreenlet** (lead.region в печатном шаблоне) — цепочка selectinload

   предзагруженное.

## Design decisions

1. **Плейсхолдеры кириллицей и словарная замена, НЕ Jinja**: пользовательский
   шаблон в Jinja = произвольный код на сервере (RCE). Токены {Клиент} и т.п.
   заменяются регэкспом из белого словаря; неизвестные остаются видимыми.
2. **Логотип в PDF — data URI** (base64 в HTML): WeasyPrint не ходит по HTTP
   за картинками (сессия/аутентификация), файл читается напрямую; HTML-превью
   показывает тот же URI.
3. **Один PrintTemplate на вид документа** (kind уникален): intro/conditions/
   signature. Счёт и договор (фаза 21) добавят свои kind.
4. **tax_note строкой** (например «НДС не облагается (УСН)») вместо
   структуры НДС — владельцу нужен один понятный параметр; расчёт НДС сверху
   вернём, если появится ОСНО.

## Известные ограничения

1. Предпросмотр текстов — только через печатную форму конкретного КП
   (/quotes/{id}/print?preview=1); абстрактного «превью с рыбой» нет.
2. Логотип один на все документы (kind не различает).
3. История изменений текстов не ведётся.

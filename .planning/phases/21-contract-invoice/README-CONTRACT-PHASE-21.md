## Design decisions

1. **Document.quote_id (ADD COLUMN)** — явная связь счёта/договора с КП
   (альтернатива «искать по заголовку» хрупка); страница счёта ссылается на КП.
2. **Оплата только полная** (paid_at + paid_amount=amount) — частичные оплаты
   (график) — по потребности, v2.0 не делаем.
3. **Договор без PDF**: docx2pdf в Linux-контейнере не работает; договор как
   редактируемый Word — это норма процесса (юрист правит), PDF-печать при
   необходимости добавим через WeasyPrint-версию шаблона.
4. **Дефолтный шаблон договора создаётся кодом** (storage/contract_template.docx,
   вне git) и заменяем файлом — владелец может положить свой docx с теми же
   Jinja-тегами.
5. **Синхронизация оплаты** — только mark_invoice_paid: сделка paid+closed_at,
   лид → 6 через change_stage (с историей), ошибки воронки не валят оплату.

## Известные ограничения

1. Частичные оплаты/график платежей не реализованы.
2. Договор — только docx (без PDF-версии).
3. document count в табе «Документы» карточки лида теперь включает счёт/договор.

## Design decisions

1. **price (с НДС) хранится, а не считается на лету** — единая точка для КП/счёта/
   аналитики; пересчитывается из price_out×(1+vat/100) при каждом сохранении.
2. **Импорт цены поставщика → price_in** (входящая б/НДС) — семантика по решению
   владельца; отпускные ставки руками.
3. **ABC по факту оплат** (paid-счета), не по всем КП — «деньги, а не обещания»;
   воронка видна отдельными KPI-карточками.
4. **Прибыль только там, где есть входящая цена** — честно показываем «—» вместо
   нуля, чтобы не искажать ABC.
5. **НДС-разбивка счёта скрывается**, если tax_note заполнена (УСН-режим).

## Известные ограничения

1. vat_rate по умолчанию 20% — при смене ставки правится в прайсе массово не
   автоматически (по товару).
2. ABC по менеджерам не строится (только агрегаты) — по потребности.
3. Печать КП показывает цену с НДС; НДС-сумма в КП не разбивается (разбивка — в счёте).

  поячеечно: значение входящей отсутствует в HTML строки менеджера).
- **НДС 22%** (РФ, с 01.01.2026): дефолт ставки в модели/формах/JS — 22;
  миграция поднимает существующие строки с 20% до 22% (product_prices и
  снапшоты quote_items; ставки ≠ 20 не трогаются).

## Что сделано (по согласованному плану)

Вкладка «Информация» = «Профиль клиента», 5 секций:
1. **Компания**: тип (холдинг/хозяйство/дилер/переработчик), головная компания (ссылка
   на другой лид), тип закупок, краткие ИНН/руководитель/сайт + переход в «Реквизиты».
2. **Квалификация**: уровень, приоритет, статус (не квалифицирован/в процессе/
   подтверждён/отказ — 4 состояния вместо рапсового чекбокса), индикатор ЛПР со
   ссылкой в «Контакты».
3. **Направления** (главное): таблица бизнес-линий (статус интерес/предложено/
   подтверждён/отказ, потенциал, сезон, менеджер, заметка), инлайн-правка строк,
   добавление/удаление HTMX. Названия свободные (решение владельца).
4. **Досье и теги**: досье (экс-«Комментарий для CRM») + чипы тегов с
   автодополнением из общего справочника; `#хэштэг` в досье и комментариях
   журнала автоматически становится тегом лида.
5. **Активность**: последнее действие (из Журнала) + следующий шаг (ближайшая
   открытая задача; нет задачи — красная плашка).

«Что сделано / Что нужно сделать» удалены из UI (данные перенесены миграцией,
колонки сохранены в БД для MCP/импорта). Рапсовые подписи из UI убраны,
колонки-лендинг задокументированы.
